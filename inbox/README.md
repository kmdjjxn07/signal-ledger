# 제출 파일(inbox)

편집기 모드(`.env`의 `SL_MODE=editor`)에서 화면에 입력한 내용이 여기에 `*.json` 파일로 저장됩니다.
GitHub에 올리면(Push) GitHub Actions가 서버 규칙으로 검증해 공개 원장에 반영하고,
원본 파일과 결과(`*.result.json`)를 `processed/` 폴더로 옮깁니다.

- 한 파일 안의 명령은 **전부 반영되거나 전부 거부**됩니다.
- 손으로 쓸 수도 있습니다. 형식과 예시는 `guide/inbox_examples/`를 보세요.
- 보유종목·계정 정보는 제출 파일로 만들 수 없습니다(공개 저장소이므로).
- 이 폴더의 파일은 공개됩니다.
