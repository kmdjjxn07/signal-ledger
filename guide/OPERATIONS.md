# 운영 정책

이 문서의 값 중 '새 서비스 기본값'이라고 표시한 것은 과거 시스템 설정을 복원한 것이 아닙니다.

## 1. 데이터 정본과 원장

- 정본은 DB입니다. 화면과 호환 JSON(`/api/export`)은 DB에서 생성합니다. 큰 JSON 파일을 통째로 덮어쓰지 않습니다.
- **append-only 테이블**(ORM에서 수정·삭제 시 `LedgerViolation`): 감사로그, 원본 문서, 출처, 공급자 호출 기록, 공식 가격,
  장중 관측, 투자자 수급, 가설 평가 사건, 모의운용 사건, 보유종목 거래, 거시 전망 판, 가져온 과거 기록.
- 정정은 원본을 지우지 않고 새 행을 추가해 연결합니다(공식 가격 `supersedes_id`, 가설 평가 `supersedes_id`, 보유 거래 `voids_id`).
- 모의운용 사건은 실험별 SHA-256 **해시 체인**입니다. 변조 탐지용이며 기록 내용이 사실임을 보증하지 않습니다.

## 2. 출처 등급

| 등급 | 기준 |
|---|---|
| A | 거래소·공식 통계·규제 공시·기업 공식 실적자료 등 1차 자료 |
| B | 출처와 시장 범위를 확인할 수 있는 데이터 제공처(네이버 시세, FRED 재배포 지표 등) |
| C | 신뢰할 수 있는 언론·리서치의 명시적인 보도·분석 |
| D | 미확인 게시물·소문·출처 불명 |

- **독립 근거 계산**: `origin_key`가 같은 출처(같은 보도자료를 재전재한 기사)는 1개로 셉니다. 기업 공식자료(`is_company_claim`)는
  경영진 주장일 수 있으므로 독립 근거 계산에서 최대 1개로만 셉니다.
- D등급은 브리핑 '사실'로 발행할 수 없고, D등급만으로 가설을 발행할 수 없습니다.

## 3. 시장 구분 (혼용 금지)

KRX 정규장 가격 / NXT / 애프터마켓 / 호가 / 체결가 / 은행 고시환율 / 서울 외환시장 환율 / NDF / 공식 일별 종가 / 장중 참고 시세는
서로 다른 값입니다. 공식 평가·가설 판정·정산은 **KRX 정규장 공식 일별 종가**만 씁니다. 장중 참고 시세는 B등급 참고이며,
모의체결 근거로는 원본 필드 검증을 통과한 KRX 정규장 관측만 씁니다. 누락된 시장·세션·시각은 추측해 채우지 않습니다.

## 4. 거래소 캘린더

- 연도별 휴장일 목록을 소유자가 KRX 공식 공지로 확인해 '확인됨'으로 등록해야 그 연도의 거래일을 판단합니다.
- 확인되지 않은 연도는 `unknown`이며 브리핑·판정·모의운용 작업이 실행되지 않습니다.
- 임시휴장·특별 거래시간(예: 수능일 개장 지연)은 공지 URL과 함께 예외로 추가합니다.
- 정규장 기본값 09:00–15:30은 연도별로 바꿀 수 있습니다.

## 5. 예약 작업

| 작업 | 시각 | 권한(scope) | 하는 일 |
|---|---|---|---|
| `pre_brief` | 관리자 설정 | briefing.write | 직전 거래일 KRX 지수, 해외 지표, 공시 → 개장 전 브리핑, 당일 close를 scheduled로 생성 |
| `close` | 관리자 설정 | briefing.write, prices.write, hypothesis.evaluate | KRX 공식 가격 동기화 → 마감 브리핑 → 가설 평가 |
| `intraday_audit` | 10·11·12·13·14·15시 | audit.read | 원장 해시 체인 검증·상태 기록. **판단·주문·체결을 만들지 않음** |
| `paper_engine` | 정규장 중 10분 목표 | paper.trade | 모의판단 엔진 |
| `settlement` | 관리자 설정 | paper.settle | 기간 종료 실험 정산 |

- 실행 잠금(`job_locks`, 만료 있음), 멱등성 키(`job_runs`의 작업명+슬롯 유일), 실패 시 같은 슬롯 재시도(작업별 최대 횟수),
  시작·완료 시각, 마지막 성공, 다음 예정 시각을 기록합니다. 시간 제한은 외부 호출 타임아웃 + 초과 여부 기록 방식입니다.
- 예약 시각 저장은 '등록'일 뿐이며, 실제 성공은 `job_runs.status=succeeded`로만 판단합니다.
- 놓친 일일 작업은 같은 날 안에서만 따라잡습니다. 휴장·캘린더 미확인일에는 아무 작업도 예약되지 않습니다.

## 6. 브리핑

- 상태: `scheduled` → `draft` → `published`, 또는 `withheld`(보류). 모든 판을 보존하고 화면은 최신 발행판을 보여줍니다.
- 개장 전: 검증된 사실이 1건 이상이면 발행, 없으면 보류. 당일 close가 이미 있으면(발행본 포함) 지연된 개장 전 작업이 건드리지 않습니다.
- 마감 후: **KRX 공식 코스피·코스닥 종가·거래량·거래대금이 모두 확인돼야** 발행. 아니면 보류판만 추가하고 마지막 정상본을 유지합니다.
  시장 전체 수급은 현재 공급자가 없어 '연결 필요'로 표시합니다(발행 필수 항목에서는 제외 — 이 판단은 새 서비스 기본값).
- 휴장일에 당일 종가를 만들거나 전 거래일 값을 복제하지 않습니다.
- AI 해석은 'AI 제안' 표시가 붙고 사실과 분리됩니다. AI가 없으면 해석은 소유자가 초안으로 작성합니다.

## 7. 기업 심층검증

9항목: 수익구조와 전문용어 / 경쟁기업 2곳과 차이 / 장점과 현재 의미 / 비용구조 / 비용구조·현금흐름 지속성 /
B2B·B2C와 고객 구매 이유 / 시장지위·점유율 전략·실효성 / 고객 전환비용과 순위 추론 / 최근 긍정·부정 뉴스.

통과: 9항목 모두 조사 + 8항목 이상 확인(결론 + 확인 표시 + 독립 A~C 근거 2개 이상) + 핵심 3항목(수익구조·비용 지속성·전환비용)
확인 + 유동성 확인 + 관리종목·거래정지 아님 + 구조적 적신호 없음. 통과하면 현재 후보(최대 1개)가 되고 이전 판은 이력으로 남습니다.
미통과 판은 반드시 다음에 확인할 구체적 자료를 적어야 저장됩니다. ETF는 기업 9항목을 적용하지 않습니다(전용 경로 미구현 → 차단).

## 8. 투자 가설

- 발행 조건: 해당 종목 **최신** 심층검증 판이 통과 + 그 판에 정확히 연결(`researchRef`).
- 품질점수: 촉매·실제 개선·수급·상대강도·거시 적합성 각 0~2점. 성공확률이 아닙니다.
  - Core: 7점 이상 + 4축 이상 충족('충족' = 1점 이상, 새 서비스 정의)
  - Exploration: 6점 이상 7점 미만 + 확신도 '낮음' + 신규 A~C 촉매·유동성·KRX 기준가격·무효화 조건
  - 활성 카드 최대 3개, 그중 Exploration 최대 1개. 단기 판정 후 '중기추적'은 활성 슬롯을 차지하지 않음
- 발행 금지: 수급·가격 부재, D등급 단독, 관리종목 위험, 명백한 거시 역풍.
  수급 근거는 당일 수급 기록 또는 소유자가 등록한 A~C 출처로 충족합니다.
- 고정 필드(기준가격·기준가격 ID·방향·판정일·무효화 조건·점수 등)는 발행 후 ORM에서 변경 불가.
- 판정일: 단기 3거래일·중기 20거래일(새 서비스 기본값), 발행 시 실제 캘린더로 계산해 고정.

### 평가 (absolute-price-v1)

- 고정 판정일 KRX 정규장 종가 / 고정 기준가격 − 1. 비용·배당 전 가격변동이며 실제 체결수익과 다릅니다.
- 상승 가설은 상승, 하락 가설은 하락이면 적중. 보합은 평균에 포함, 적중률 분모에서 제외.
- 판정일 종가가 없으면 보류(분모 제외). 다른 날 가격으로 대체하지 않으며, 나중에 그 날짜 가격이 들어오면 평가합니다.
- 표본(적중+실패) 20건 미만은 '추적 중'. 과거 상대성과 기록은 `legacyRelative`로 따로 보관하며 신규 통계에 넣지 않습니다.

## 9. 모의운용

- 실험별 독립: 자본·기간·최대 보유·종목당 최대 비중·비용, 현금, 포지션, 사건. 제안 기본값: 1,000,000원 · 5거래일 · 3종목 ·
  35% · 15bp(새 서비스 기본값).
- 상태: 첫판단대기 → 운용중 → 정산대기 → 검증완료 / 폐기. 첫 실제 판단 순간 config 잠금, 그 거래일이 시작일.
- **권한 분리**: 실험마다 `execution_owner` 하나(`engine`). 판단·주문·체결 사건은 그 주체만 추가할 수 있습니다.
  감사·정산 작업은 판단·주문·체결을 만들 수 없습니다. 엔진 장애를 이유로 권한을 넘기지 않습니다.
- **판단 엔진**: 후보(활성 가설·현재 연구 후보) 중 필수 데이터를 모두 갖춘 서로 다른 업종 최대 3개를 AI가 비교 → 서버가 점수·필수
  요건·위험 검증. 공급자 미연결·호출 실패는 **운영 오류**로 기록하며 판단 사건을 만들지 않습니다(실험 시작도 안 됨).
- 주문 필수 요건: 신규 A~C 촉매(14일 이내), KRX 공식 가격, 거래대금(10억 원 이상, 새 서비스 기본값), **당일 종목별 수급**,
  업종, 무효화 가격·조건, 이벤트 위험, 비용 후 보상 시나리오, 현금·비중, 고정 기간.
- 위험 검증: 정수 수량, 현금(비용 포함), 최대 보유 수, 종목당 비중, 섹터 50%, 탐색 비중 NAV 10~15%·동시 1개,
  **무효화 손실 + 왕복 비용 ≤ NAV 1%**. 갭·유동성 악화 시 손실이 더 클 수 있습니다.
- **즉시 체결**(`active-paper-v2` / `immediate-paper-v1`): 판단·주문 저장 → 원본 시세를 새로 조회 → 결정 이후 첫 적격 KRX 정규장
  관측 → 원자료·수신 시각 모두 결정 후 120초 이내 → 체결가로 위험 재검증 → fill 1건 추가. 창 안에 적격 관측이 없으면 만료,
  재검증 실패면 취소. 이월 없음. 중복 체결은 멱등성 키로 차단.
- 종료: 기간 종료 시 신규 판단·주문·체결 차단, 남은 주문 만료, 강제 매도 없음. 종료일 KRX 공식 종가로 평가하고
  현금·수량·비용 재계산·해시 체인을 검증하면 검증완료. 가격이 없으면 기간 연장 없이 정산대기.
- 성과: 검증완료 실험의 비용 후 절대수익률 산술평균(수익·손실 모두). 0건이면 '산출 대기'.
- `liveExecutionVerified`: 적격 관측에 연결된 fill + 해시 체인 통과 + 그 이후 정시 감사 성공이 있어야 true.

## 10. 보안

소유자 전용 로그인(scrypt), DB에는 세션 토큰 해시만 저장, 모든 쓰기 요청에 CSRF 토큰 + 같은 출처 검사, 로그인 실패 5회/15분 잠금,
CSP(`default-src 'self'`)·X-Frame-Options·nosniff, 템플릿 자동 이스케이프, ORM 바인딩(SQL injection 방지), 비밀키는 환경변수 전용이며
화면·API·감사로그·저장 URL에서 가립니다(`crtfc_key` 등 제거). 외부 문서·AI 응답은 자료로만 다루고, AI 입력에 보유종목·원장·비밀값이
들어가면 호출 전에 거부합니다. AI 출력은 서버가 스키마와 규칙으로 다시 검증합니다.
